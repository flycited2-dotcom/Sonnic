# Sonnic

Первый локальный прототип сервиса рефлексии о снах. Можно напечатать сон или воспользоваться голосовым вводом поддерживаемого браузера, исправить текст и открыть бесплатный **демонстрационный** результат.

По умолчанию включено demo: найденные слова и подготовленный текст. С 2026-09-06 выбран отдельный проект ChatGPT и мост к Sonnic без OpenAI API. [Пакет базы знаний](chatgpt-project/README.md) и локальная очередь на синтетических заданиях готовы; проект ChatGPT заполнен 11 файлами, закреплён и прошёл первый ручной синтетический тест. Автоматический транспорт и возврат в интерфейс сайта ещё не реализованы. [Статус этапа 03](docs/stages/03-chatgpt-project-bridge.md). Прежний OpenAI-адаптер сохранён как отложенная возможность, ключ не требуется для текущего пути. Библиотека из 12 источников ещё не подключена к поиску в приложении. Платежей, подписки и публикаций нет.

## Быстрый запуск на этом компьютере

Зависимости уже установлены в папке проекта. Откройте **Start-Sonnic.cmd** двойным щелчком. Когда появится сообщение `Sonnic is ready`, откройте [Sonnic](http://127.0.0.1:3000).

Окно запуска нужно оставить открытым. Чтобы остановить оба сервера, нажмите Enter в этом окне. Если порты 3000/8000 заняты предыдущим запуском, сначала остановите его. Скрипт не завершает посторонние процессы.

На новом компьютере нужны Node.js 22+ и Python 3.12+. Сначала запустите **Setup-Sonnic.cmd**: он скачает зависимости, затем пользуйтесь Start-Sonnic.cmd. Доступ к интернету нужен при установке. В Windows не требуется вручную активировать виртуальное окружение.

## Что попробовать

1. Нажмите «Вставить пример» или напишите свой рассказ от 20 до 10 000 символов. Можно добавить чувство, повторяемость, дату и добровольный контекст.
2. Для голоса выберите **язык распознавания** и нажмите «Наговорить сон». Браузер запросит разрешение на микрофон. «Остановить и вставить» добавит финальный текст к уже написанному; «Отменить запись» сохранит исходный текст. Исправьте распознанные слова перед отправкой.
3. Нажмите «Посмотреть демо-разбор». Результат отмечен как demo. После обновления вкладки текущая запись открывается снова, пока действительна гостевая сессия.
4. «Записать другой сон» начинает новую запись; предыдущая остаётся в локальной базе. «Удалить этот сон» удаляет текущую запись, результат и связанные события. Полноценного дневника со списком пока нет.
5. RU/EN меняет интерфейс. Уже сохранённый результат остаётся на языке, выбранном при отправке. Язык рассказа и культурный контекст не меняются от переключения интерфейса.

## Голос: что работает и где граница

Используется браузерный **Web Speech API** с проверкой наличия `SpeechRecognition` / `webkitSpeechRecognition`. Возможность доступна не во всех браузерах и регионах. Даже наличие API не гарантирует доступность сервиса. В неподдерживаемом браузере текстовый ввод остаётся рабочим.

Сервис распознавания браузера может отправлять звук внешнему поставщику; это указано перед нажатием микрофона. Ключ для серверного AI Sonnic для этой функции не нужен. Sonnic не создаёт и не сохраняет аудиофайлы, но не управляет хранением у поставщика браузерного распознавания. Остановка или отмена не может отозвать уже переданный ему звук. Для распознавания могут требоваться интернет и доступ к микрофону; локальный адрес работает в безопасном контексте браузера. Одна сессия ограничена двумя минутами, её можно повторить.

Обработаны отказ в разрешении, отсутствие микрофона, сетевой сбой, отсутствие речи, неподдерживаемый язык, таймаут и отмена. Автотесты проверяют интеграционный контракт с подставным распознавателем. **Живой микрофон и качество транскрипции не проверены**. Подробнее: [этап 01](docs/stages/01-local-foundation.md).

Ограничения проверены по [MDN SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition), семантика отмены — по [abort](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/abort), типы ошибок — по [SpeechRecognitionErrorEvent](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognitionErrorEvent/error).

## Ручной запуск для разработчика

Из корня проекта, в первом PowerShell:

```powershell
.venv\Scripts\python.exe -m uvicorn apps.api.sonnic.main:app --host 127.0.0.1 --port 8000
```

Во втором PowerShell, также из корня:

```powershell
npm.cmd run dev
```

Для macOS/Linux создайте `.venv` через `python3 -m venv .venv`, установите `requirements.txt`, выполните `npm ci` и замените путь Python в командах на `.venv/bin/python`. Эти ОС в данном этапе не проверялись.

Интерактивное описание API: [Swagger](http://127.0.0.1:8000/docs). Проверка готовности: [health/ready](http://127.0.0.1:8000/health/ready). При ручном запуске Ctrl+C останавливает соответствующий сервер.

Настройки необязательны: значения по умолчанию работают локально. Пример `.env.example` можно скопировать в `.env` в корне. `AI_MODE=demo` включает шаблон, `AI_MODE=disabled` выключает разбор. `AI_MODE=real` включает OpenAI только с ключом, двумя моделями и `AI_ALLOW_PAID_REQUESTS=true`; неполные настройки останавливают запуск. Готовый `.env` оставлен в demo, ключ пуст. `SONNIC_DB_PATH` задаёт путь базы относительно корня. В `apps/web/.env.local` можно задать `API_ORIGIN` из примера; после изменения перезапустите web.

## Хранение и доступ

API и web слушают только `127.0.0.1`. В cookie хранится случайный HttpOnly-токен, в базе — его хеш. Сессия действует 24 часа; истечение доступа само по себе не удаляет записи. В браузере сохраняются только язык интерфейса и ID текущего сна; черновик без отправки существует в памяти вкладки. Дневник не отправляется в обычные логи, ошибки API не возвращают исходный текст. SQLite пока не зашифрована: это локальный прототип, не размещайте его в публичном доступе. Удаление записи — логическое удаление из базы, не гарантия стирания остаточных байтов с диска.

У сессии сохраняются first-touch `utm_source`, `utm_campaign`, `content_key`. События отправки и просмотра связаны с ID; выручки и полноценной атрибуции контент-каналов ещё нет. Лимит 10 новых снов в час на сессию — локальное ограничение, не защита публичного сервиса от злоупотреблений.
