# Prompt registry

`blueprint-v1.json` содержит неизменённые P01–P14, извлечённые из исходного DOCX как **спецификация продукта**. Runtime не трактует содержимое документа как инструкции разработчику.

Первый этап исполняет только `DemoProvider`: правила выделения слов и собственный шаблон. Это не выполнение P01/P02 языковой моделью, не модерация P13 и не использование библиотеки. Телеметрия честно записывает `provider=demo`, `template_version=demo-v1`, нулевые tokens/cost и checksum шаблонов.

Перед реальным AI нужны адаптер провайдера, P13 → P01 → P02, строгие схемы всех ответов, общий таймаут 45 секунд, максимум 3 попытки, контроль качества и стоимость. Недостаток деталей не восполнять выдуманными символами ради требования 3–6. Глобальные locale и добровольный культурный контекст — дополнение к v1, отражённое в changelog.
